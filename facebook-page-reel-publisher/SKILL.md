# Facebook Page Reel Publisher

Move one identified, ready-to-post video from a prepared package to a verifiable Facebook Page Reel. Keep preparation, submission, and confirmed publication as separate states.

## Establish the post

- Identify the exact video file and version, target Page, caption, optional cover, and requested audience, schedule, AI label, Story sharing, group sharing, and paid-promotion settings. Use choices already established in the current task; ask only for information needed to avoid posting the wrong item or to the wrong destination.
- A request to plan or draft ends before submission. A clear request to publish this identified post authorizes the Share/Publish action without a second ritual phrase.
- Review existing publication receipts and the Page's recent Reels before upload. If this asset is already published to the intended Page, report its direct link and supporting evidence. Compare a file hash when available. A revised caption or cover alone does not silently authorize a duplicate upload.

## Prepare and submit

1. Confirm the selected video exists and plays with the expected picture, sound, duration, and orientation. Compare the caption with the approved copy. Check time-sensitive factual claims against current primary sources when the post makes them.
2. Use an available, user-authorized publishing interface. For an Android device, check the current connection before transferring media and confirm the exact file in the picker by thumbnail and duration. For a browser uploader, verify the selected media in the browser UI. Do not trust saved device addresses, tap coordinates, or account state.
3. Enter the target Page's Reel composer. Select the media, set the supplied cover, and enter the caption. Compare the complete editor text with the prepared copy where the interface allows it.
4. Inspect the actual audience, schedule, AI label, Story and group sharing, and paid-promotion controls. Set each according to this post's instructions; app defaults may vary. A Reel upload does not authorize an ad campaign. Immediately before submission, verify that the composer still shows the intended Page as the posting identity, along with the correct media, caption, and settings.
5. Submit once. A spinner, delayed Page update, lost response, or upload notification without a Reel readback leaves the result uncertain; it does not authorize another submission.

## Read back and record

- Check the intended Page's Reel list. Open the new item and verify its Page attribution, requested audience indicator, cover, caption, and playable media. Expand the caption when a source, disclosure, or caveat is critical to the post. Copy the direct URL from that published Reel.
- Save a compact receipt with the asset version and hash, caption reference, target Page, requested settings and observed states, submission and readback times, direct URL, and relevant UI evidence. Record the exact verification surface: a signed-in app view is not an independent anonymous public-web check.
- If publication remains uncertain, inspect upload notifications, the Page list, and earlier receipts before considering a retry. If login or identity verification blocks direct-link checking, report that limit separately from signed-in publication evidence.

Report the direct Reel link only after readback. Otherwise report the precise stopping point and next actionable step without calling the post live.
